# Projects

## Realtime Voice Playground

<GitHubLink href="https://github.com/vpalmisano/realtime-voice-playground" />

An interactive webapp for trying voice AI — either end-to-end realtime models (OpenAI, Google, ElevenLabs) or a custom STT → LLM → TTS pipeline with different providers. Configure options, chat by text or mic, and optionally run scripted Q&A with webrtcperf-js.

[Demo page](https://vpalmisano.github.io/realtime-voice-playground/)

## WebRtcPerf

<GitHubLink href="https://github.com/vpalmisano/webrtcperf" />

WebRtcPerf is an open-source tool designed for testing WebRTC services with multiple concurrent client connections, measuring the most important RTC statistics and collecting them in an easy way. This documentation will dive into its multiple features and configuration options, showing you how to leverage this tool to gain valuable insights into your real-time communication solutions.

[Docs](https://vpalmisano.github.io/webrtcperf/)

## webrtcperf-js library

<GitHubLink href="https://github.com/vpalmisano/webrtcperf-js" />

A browser library used by the webrtcperf tool to capture the RTC logs and run page inspection/automation. It can also be used stand-alone importing the javascript package into the page before loading the other javascript sources. It contains some utilities to debug the page RTC connections, the getUserMedia and getDisplayMedia, evaluate the end-to-end delay, etc.

[Docs](https://vpalmisano.github.io/webrtcperf-js/)

## Virtual Background webcam effect

<GitHubLink href="https://github.com/vpalmisano/virtual-background" />

This project implements a virtual background effect for webcam video streams directly in the browser. It allows users to select their webcam, apply effects like blur, and change their background, similar to features found in popular video conferencing applications.

[Demo page](https://vpalmisano.github.io/virtual-background/)

## Throttler

<GitHubLink href="https://github.com/vpalmisano/throttler" />

A Linux tool that allows to apply network constraints to a single or a group of processes.

[Docs](https://vpalmisano.github.io/throttler/)

## WebRTC Internals Exporter

<GitHubLink href="https://github.com/vpalmisano/webrtc-internals-exporter" />

A Chromium browser extension that allows to collect WebRTC stats and export them to a Prometheus PushGateway service.

[Chrome Extension](https://chromewebstore.google.com/detail/webrtc-internals-exporter/jbgkajlogkmfemdjhiiicelanbipacpa)

[Docs](https://vpalmisano.github.io/webrtc-internals-exporter/)
